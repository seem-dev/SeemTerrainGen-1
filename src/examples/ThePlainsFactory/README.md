# The Plains Factory - SeemTerrainGen-1 Map-Config
Hello everyone! Following the [tutorial](https://youtu.be/vJIZr__O41A), I have uploaded the finished configs so you can view and use them.

I recommend using them and following the tutorial to learn in the best way and get more known to configs.

## Need to know
Every config can be used as a standalone map, as they are all the same, just that the `Instancing` parameter is moved and changed.

If you want to use configs with the instances (in Instances_Included), please also drag the rbxm file (DragIntoYourPlace) into your place and ungroup in the workspace. 
These are needed for the configs with instances, otherwise an error will occur because they are not found.
